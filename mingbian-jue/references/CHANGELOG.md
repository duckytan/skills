## 自升级系统（v3.0.2 补强 · 含 P 模式 · 完整版见 references/auto-upgrade.md）

**錡哥拍板（15:20）**："如果是非常严重的错误（你自行判断），直接全自动升级修复"

**失误捕获器**（5+N）：A:⏳脚本 / B:cron / C:启动 / D:空目录 / E:message 空 + AI 推断

**严重度**：`结果(1-3) + 影响面(1-3) + 可逆性(1-3) - 修复成本(0-2)`

| 分数 | 等级 | 行动 | 拍？|
|------|------|------|----|
| ≥ 7 | 🔴 P0 | **全自动修复** | 否 |
| 5-6 | 🟡 P1 | 写 incident + 提示錡哥 | 是 |
| < 5 | 🟢 P2 | 仅记录 | 是（批次）|

**🔴 P0 场景**：5 失误全中 / SKILL.md 本应避免但犯 / 全局影响 / 数据丢失

**文件**：`incidents/YYYY-MM-DD-inc-NNN.md` + `auto-fixes/` + `reviews/`

**周升级**：每周一 9:00 cron（`scrutiny-weekly-upgrade`）：跑 `catch_incidents.py` 扫全工作区 → 汇总 → 🔴 P0 全自动修 SKILL.md + 🟡 P1 提示錡哥 → 写 `reviews/YYYY-MM-DD-weekly-review.md`
