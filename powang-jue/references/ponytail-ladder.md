# ponytail 7 级阶梯 · 法执显现示例（非写码 recipe）

> 本文件为破妄诀 §5.2 与编排层「奥卡姆闸门」的**唯一权威源**。主文件（sansi-huishen / powang-jue）不内嵌阶梯原文，改动只在此处。

> 文化锚：奥卡姆剃刀「如无必要，勿增实体」+ 老子「损之又损，以至于无为」。每一级都是「再砍一层」。

写码 / 改码前，从顶到底逐级下探，**能停则停，不做则已，做则最小**：

1. YAGNI（能否不做）—— 默认不做；新增功能先论证「为什么必须有」
2. 复用（能否复用现有代码 / 模式）—— 优先在代码库内找现成实现
3. 标准库（语言 / 运行时自带）—— 次选标准库能力，不引新依赖
4. 平台原生能力 —— 再选运行时 / 平台原生 API
5. 已装依赖（项目已引入的）—— 仍不够才用已装第三方依赖
6. 一行 / 最小改动 —— 能用一行或极小 diff 解决就别铺开
7. 最小可用实现 —— 必须写时，写刚好够用的最小实现，不留空扩展层

**约束**：本阶梯是「法执显现示例」，不是写码 recipe。一旦出现「该写什么」的操作指令即越界，退回审查视角。
