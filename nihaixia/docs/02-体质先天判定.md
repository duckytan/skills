## 🎯 这是什么

**倪海厦中医问诊的"先天体质判定"环节**——基于八字排盘，输出**倪师视角下的先天体质五行偏向**，作为问诊十问的**前置参考输入**（可选）。

**核心理念**：倪师原话——
> "如果知道病人八字五行，可明白体质弱点，非常有助于诊断。"（来源：`references/raw/天纪-天机道-raw.txt`）

八字 = 先天体质（静态背景）· 十问 = 当前症状（动态现场）= **两层叠加 = 综合诊断**

## 🔧 解盘算法（已验证准确）

**使用库**：`lunar-python==1.4.8`

**安装命令**（首次使用前必跑）：

```bash
pip install lunar-python==1.4.8
```

**验证安装**：

```bash
python3 -c "from lunar_python import Solar; print('OK')"
# 输出 OK = 安装成功
```

**常见安装问题**：

| 报错 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'lunar_python'` | 未安装 | `pip install lunar-python==1.4.8` |
| `externally-managed-environment` (PEP 668) | 系统 Python 受保护 | `pip install --break-system-packages lunar-python==1.4.8` 或用虚拟环境 `python3 -m venv .venv && source .venv/bin/activate && pip install lunar-python==1.4.8` |
| `pip: command not found` | 未装 pip | `python3 -m ensurepip --user` |
| 多 Python 环境冲突 | 系统有 python2 + python3 | 明确用 `python3 -m pip install ...` |
| 装上了但仍报错 | 虚拟环境问题 | `pip install --user lunar-python==1.4.8` |

**算法说明**：基于 lunar-python 的标准八字排盘，输出年柱/月柱/日柱/时柱、纳音、日主五行、藏干、十神等字段。所有字段均经过传统命理公式验证（子平真诠·沈孝瞻）。

**调用示例**：

```python
from lunar_python import Solar

def bazi_judgment(year, month, day, hour=12, minute=0):
    solar = Solar.fromYmdHms(year, month, day, hour, minute, 0)
    lunar = solar.getLunar()
    bazi = lunar.getEightChar()
    
    return {
        'year_pillar': bazi.getYear(),
        'month_pillar': bazi.getMonth(),
        'day_pillar': bazi.getDay(),
        'time_pillar': bazi.getTime(),
        'year_na_yin': bazi.getYearNaYin(),
        'day_na_yin': bazi.getDayNaYin(),
        'day_master': bazi.getDay()[0],  # 日干
        'day_wu_xing': bazi.getDayWuXing(),
        'year_shi_shen': bazi.getYearShiShenGan(),
        'month_shi_shen': bazi.getMonthShiShenGan(),
        'time_shi_shen': bazi.getTimeShiShenGan(),
        'day_hide_gan': bazi.getDayHideGan(),
    }
```

## 🔄 5 字段 → 10 问对接表（v1.2 · 公共版）

> **问题**：5 字段（先天体质）怎么映射到十问（动态症状）？
> **解决**：基于"五行-脏腑"映射，建立"体质判定 → 问诊重点"对接表

### 五行-脏腑-问诊对接

| 5 字段（先天）| 关键五行 | 对应脏腑 | 十问重点项（按优先级）|
|-------------|---------|---------|--------------------|
| **缺金** | 金弱 | 肺·大肠·鼻·皮·便 | 睡眠（1-3点/3-5点醒）、大便（稀/干）、皮肤干燥、鼻塞咳嗽 |
| **缺木** | 木弱 | 肝·胆·目·筋 | 睡眠（11-1点醒）、眼睛干涩、情绪抑郁、月经周期 |
| **缺火** | 火弱 | 心·小肠·舌·血 | 手脚冰凉、面色苍白、舌淡、畏寒 |
| **缺水** | 水弱 | 肾·膀胱·耳·骨 | 腰膝酸软、耳鸣、夜尿频、房事问题 |
| **缺土** | 土弱 | 脾·胃·口·肉 | 胃口差、腹胀、大便稀溏、肌肉消瘦 |
| **日主旺（火旺）**| 火过旺 | 心火亢盛 | 口苦口干、烦躁、五心烦热、失眠 |
| **日主旺（水旺）**| 水过旺 | 肾阳虚寒 | 畏寒肢冷、夜尿多、痰多清稀 |
| **日主旺（土旺）**| 土过旺 | 痰湿内蕴 | 痰多、舌苔厚腻、身体困重 |
| **日主弱（火弱）**| 火不足 | 阳虚外寒 | 喜温喜暖、四肢不温、面色苍白 |
| **日主弱（木弱）**| 木不足 | 肝血不足 | 头晕目眩、月经量少、抽筋 |
| **日主弱（金弱）**| 金不足 | 肺气虚 | 易感冒、气短、声音低弱 |
| **日主弱（水弱）**| 水不足 | 肾阴虚 | 五心烦热、口干咽燥、盗汗 |
| **日主弱（土弱）**| 土不足 | 脾气虚 | 纳差腹胀、倦怠乏力、大便溏 |

### 叠加公式（公开版）

```
体质类型 × 症状主诉 = 主证
喜用 × 忌神 = 用药方向

冲突时：十问权重 0.7、八字权重 0.3（症状更直接）
不冲突时：八字+十问指向同一方向 → 置信度升级为 HIGH
```

### 问诊时序（公开版·建议）

> 用户场景不同，可灵活选顺序。下面是公开推荐的 SOP。

**路径 A（症状优先 · 推荐）**：

```
【阶段 1】症状入口（01）先收 5 项关键问诊
  - 主诉 / 睡眠 / 大便 / 胃口 / 寒热
  - 用户真实场景：先说症状
  
【阶段 2】再要八字（02）
  - 拿到出生日期 + 时辰
  - 跑 bazi_paipan.py

【阶段 3】再补剩余 5 项十问
  - 出汗 / 体力 / 情绪 / 渴 / 舌象
  - 八字已知后，问诊更聚焦
```

**路径 B（八字优先 · 适合养生规划）**：

```
【阶段 1】先要八字（02）
  - 公历生日 + 时辰
  - 跑 bazi_paipan.py
  
【阶段 2】完整十问（01）
  - 一次性收齐 10 项
```

### 应用示例（公开版 · 虚拟案例）

**案例 1：缺金体质**

| 阶段 | 内容 |
|------|------|
| **02 输出** | 喜土水·缺金·肺阴虚倾向 |
| **01 主诉** | 失眠（3-5点醒）+ 大便干 + 口干 |
| **叠加** | 缺金（02）+ 3-5点醒+便干（01）= 肺阴虚·大肠津亏 |
| **置信度** | 不冲突 → HIGH（八字体质+症状一致）|
| **用药方向** | 滋阴润肺 + 通便（土·水方向）|

**案例 2：痰湿体质**

| 阶段 | 内容 |
|------|------|
| **02 输出** | 喜木火金·缺木金·痰湿内蕴（MEDIUM）|
| **01 主诉** | 痰多 + 身体困重 + 腹胀 |
| **叠加** | 痰湿（02）+ 痰多困重（01）= 痰湿内蕴（HIGH 升级）|
| **用药方向** | 健脾化痰（木·土方向）|
