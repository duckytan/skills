## 8 关系分 2 层

> **5 维不是孤立的 5 个工具**——是**网络化关系**，5 维之间有 8 种关系动态平衡。  
> **v4.0.3 修正**（般若虾建议 3）：**8 关系分 2 层**——**4 基础必走 + 4 高级可选**。

---

## 2.1 基础操作（4 关系 · 默认必走）

> 适用于**日常决策**——15-20 分钟五维复盘就是这 4 关系。

### 2.1.1 相生（5 对 · 顺势转化）

- **木生火**：太初 → 观复（拆 → 推演）
- **火生土**：观复 → 洞观（行动 → 回路）
- **土生金**：洞观 → 颠倒（看整体 → 找致命）
- **金生水**：颠倒 → 知几（找失败 → 更新概率）
- **水生木**：知几 → 太初（概率 → 拆基本事实）

**相生链**（5 维完整工作流）：

```
木 → 火 → 土 → 金 → 水 → 木（循环）
拆     推    容    断    流    归
```

### 2.1.2 相克（5 对 · 制衡约束）

- **木克土**：太初 → 洞观（看个体 → 看整体）
- **土克水**：洞观 → 知几（看回路 → 看概率）
- **水克火**：知几 → 观复（概率推 → 行动推）
- **火克金**：观复 → 颠倒（推演 → 找失败）
- **金克木**：颠倒 → 太初（找失败 → 拆基本事实）

**相克链**：每维都被另一维约束，**防止单维主导决策**。

### 2.1.3 相乘（过度克）+ 相侮（反向克）

- **相乘**：克方过强（如金过强克木太深）= 决策被单一思维压死
- **相侮**：被克方反克（如木反克金）= 决策反弹
- **应对**：**顺势转化**（不是压下去）——把相乘转化为相生（用别的维缓解）

## 2.2 高级动态（4 关系 · 重大决策才用）

> ⚠️ **本节不进入基础复盘**——重大决策（30+ 分钟）才考虑。  
> 般若虾建议：**化害胜复在中医语境有特殊含义**——v4.0.4 重新定义为现代博弈语言。

| 术语 | 重定义 | 修仙术语 |
|---|---|---|
| **化** | 相克转化为相生 | 转炼诀 |
| **害** | 隐蔽的相克 | 伏煞诀 |
| **胜** | 一方克胜另一方（暂时主导）| 制胜诀 |
| **复** | 被克方反扑（克胜的延续）| 归根诀 |

**化害胜复 = 4 种复杂动态**——决策时遇到，按"先化（转炼）再胜（制胜）最后复（归根）"处理。
