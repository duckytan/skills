## 加载策略

**简单问题**（饮食/养生/基础辨证）：
- 不加载 modules/，用 SKILL.md 主体速查表 + references/qa-quickref.md

**具体条文问题**（"伤寒论第 X 条讲什么"）：
- 加载 `modules/01` 或 `02`

**具体医案**（"倪师治过乳癌吗"）：
- 加载 `modules/03`

**杂病/金匮**（"金匮里治肝硬化"）：
- 加载 `modules/04`

**内经理论**（"上古天真论怎么说"）：
- 加载 `modules/05` 或 `08`

**梁冬对话**：
- 加载 `modules/06`

**重病/汉唐**：
- 加载 `modules/07`

**针灸/药物**：
- 加载 `modules/09`

**逐条条文精读 / 模仿倪师语气**：
- 加载 `modules/10`

## 注意事项

- `modules/10_perspective_verbatim.md` 含完整 SKILL.md frontmatter（来自独立 skill 合并），不影响加载
- modules/01-09 头部都有「从 SKILL.md 第 X-Y 行提取」说明（早期拆分记录）
- 总计 ~72000 行（约 6.1M），不要一次加载多个
