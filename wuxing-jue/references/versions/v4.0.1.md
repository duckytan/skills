## 2. 8 关系动态平衡（核心创新）

> **5 镜不是孤立的 5 个工具**——是**网络化关系**，5 镜之间有 8 种关系动态平衡。

### 2.1 相生（5 对 · 顺势转化）

- **木生火**：第一性 → 二阶（拆 → 推演）
- **火生土**：二阶 → 系统（行动 → 回路）
- **土生金**：系统 → 逆向（看整体 → 找致命）
- **金生水**：逆向 → 贝叶斯（找失败 → 更新概率）
- **水生木**：贝叶斯 → 第一性（概率 → 拆基本事实）

**相生链**（5 镜完整工作流）：

```
木 → 火 → 土 → 金 → 水 → 木（循环）
拆     推    容    断    流    归
```

### 2.2 相克（5 对 · 制衡约束）

- **木克土**：第一性 → 系统（看个体 → 看整体）
- **土克水**：系统 → 贝叶斯（看回路 → 看概率）
- **水克火**：贝叶斯 → 二阶（概率推 → 行动推）
- **火克金**：二阶 → 逆向（推演 → 找失败）
- **金克木**：逆向 → 第一性（找失败 → 拆基本事实）

**相克链**：每镜都被另一镜约束，**防止单镜主导决策**。

### 2.3 相乘（过度克）+ 相侮（反向克）

- **相乘**：克方过强（如金过强克木太深）= 决策被单一思维压死
- **相侮**：被克方反克（如木反克金）= 决策反弹
- **应对**：**顺势转化**（不是压下去）——把相乘转化为相生（用别的镜缓解）

### 2.4 化 + 害 + 胜 + 复（复杂动态）

- **化**：相克转化为相生（如木克土 → 通过"先看整体再拆个体"转化为"看整体前先拆关键"）
- **害**：隐蔽的相克（看似相生实则相克）
- **胜**：一方克胜另一方（暂时主导）
- **复**：被克方反扑（克胜的延续）

**化害胜复 = 4 种复杂动态**——决策时遇到，按"先化（转化）再胜（克胜）最后复（反扑）"处理。

## 3. 协作规则（3 条铁律）

1. **不单独用**——任何 1 镜必配对（生/克/乘/侮/化 至少 1 关系存在）
2. **冲突时让位**——当 2 镜冲突（克我方强势），**让位 = 顺势转化**（不是压下去）
3. **极端时全用**——重大决策，5 镜 + 8 关系全跑一遍（用 §4 五镜复盘）

---

## 4. 五镜复盘（15-20 分钟 · 真能用）

> ✅ **本节 = 决策工具**。5 镜 × 1 问 + 最终 4 项 = **9 项，15-20 分钟做完**。

```markdown
## 决策：_______

### 🌳 木 · 根（第一性 · 归根曰静）
**这事的基本事实有 3 个吗？分别是什么？**

### 🔥 火 · 蔓（二阶 · 为之于未有）
**这次行动后，二阶三阶会发生什么？谁会调整行为？**

### ⛰️ 土 · 容（系统 · 厚德载物）
**这事在哪个大系统里？关键反馈环是什么？**

### ⚔️ 金 · 断（逆向 · 反者道之动）
**什么会让这事彻底失败？怎么避开？**

### 🌊 水 · 流（贝叶斯 · 上善若水）
**我现在有多少把握？什么新证据会让我改变？**

### 8 关系核验
- 哪 2 镜**相生**（顺势）？___→___
- 哪 2 镜**相克**（制衡）？___→___
- 有没有**相乘 / 相侮 / 化 / 害**？如何顺势转化？

### 最终
- **推荐方案**：_______
- **最大风险**：_______
- **失败预案**：_______
- **下次复盘时间**：_______
```

**8 关系核验 = v4.0 新加**——v3.0 之前只问 5 镜，**没问关系**——5 镜独立用 = 静态分类 = 不动态平衡。

## 5. 决策模式（3 种 · 按场景选）

| 模式 | 顺序 | 覆盖 5 镜 | 何时用 |
|---|---|---|---|
| **紧急式** | 直接行动 | **跳过 5 镜** | 已做过 + 时间紧 |
| **启发式** | 倒序金→水→木→火→土 | 全 5 镜（先证伪再推）| 日常决策（15-20 分钟）|
| **分析式** | 正序木→火→土→金→水 | 全 5 镜（从拆到流）| 重大决策（30+ 分钟）|

**正序 vs 倒序**：

- **正序木→水**：从基本事实出发 → 适合"全新问题"
- **倒序金→木**：从证伪出发 → 适合"已有方案"（先打掉失败的）
