## 关键教训（3 个）

### 教训 1：五行调研 = 误读 30+ 分钟（v2.1 → v3.0）

- 把"行"当名词、把"五行"当闭环
- 正确理解：行 = 动词（运动）· 8+ 种关系
- 出处：郑玄《洪范注》"行者，顺天行气也"

### 教训 2：v3.0 找主框架 = 反复打回（v3.0 旧版/协作版）

- v3.0 旧版：把阴阳当主框架 → 锡哥打回
- v3.0 协作版：完全删阴阳 → 锡哥说"写但不突出 ≠ 删"
- 正确做法：锡哥说"X 不突出"= **写 X + 标底色**（不是删 X）

### 教训 3：化害胜复 = 中医特殊含义（v4.0.1 → v4.0.3）

- v4.0.1 直接用"五行胜复"= **未查证** = 红风险
- 般若虾指出：中医"五行胜复"= 预测气候/疾病 = 特殊含义
- 修复：v4.0.3 重定义为现代博弈语言 + 标"高级动态"分层
