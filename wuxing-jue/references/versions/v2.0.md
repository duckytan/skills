## 1. 10 个核心模型 + 五行锚点

> **核心层 = 日常 90% 决策的必备**。五行 = 记忆锚点，方便随时调出。

| # | 模型 | 五行锚 | 老子原话 | 一句话安全锁 |
|---|---|---|---|---|
| **1** | **第一性原理** | 木 · 根 | 「归根曰静」| 拆到不能再拆，再从零搭 |
| **2** | **二阶思维** | 火 · 蔓 | 「为之于未有」| 这次行动之后，第二步是什么 |
| **3** | **逆向思维** | 金 · 断 | 「反者道之动」| 怎么保证失败 → 然后避开它 |
| **4** | **系统思维** | 土 · 容 | 「厚德载物」| 看回路，不看点 |
| **5** | **贝叶斯思维** | 水 · 流 | 「上善若水」| 带置信度的概率，遇证据就更新 |
| **6** | **证伪 / 确认偏差** | 金 · 断（防御）| — | 什么数据会推翻我 |
| **7** | **幸存者偏差** | 金 · 断（防御）| — | 注意墓地里的失败者 |
| **8** | **安全边际** | 水 · 流（缓冲）| — | 即使判断错了，也活着 |
| **9** | **激励博弈** | 火 · 蔓（推演）| — | 看懂激励 = 预测行为 |
| **10** | **复利** | 木 · 根（生长）| — | 慢就是快 |

**五行闭环（决策完整链路）**：

```
木 → 火 → 土 → 金 → 水 → 木
拆     推    容    断    流    回
根     蔓    容    断    流    归
```

## 2. 致·行·驱动三步法（每次重要决策前过一遍）

### 2.1 致（2 分钟）—— 校准到本质

| # | 模型 | 关键问题 |
|---|---|---|
| 1 | 第一性原理 | "这是什么？基本事实是什么？" |
| 6 | 证伪 | "什么数据会推翻我？" |
| 7 | 幸存者偏差 | "墓地里的失败者告诉我什么？" |
| T1 | 奥卡姆剃刀 | "同等解释力下选最简单" |

### 2.2 行（动态）—— 行动验证

| # | 模型 | 关键问题 |
|---|---|---|
| 2 | 二阶思维 | "然后呢？接下来会发生什么？" |
| 4 | 系统思维 | "整体什么样？哪些反馈环？" |
| 3 | 逆向思维 | "什么会毁掉它？砍掉致命的" |
| 8 | 安全边际 | "留多少余量？（30% 起步）" |
| 9 | 激励博弈 | "对方激励是什么，他会怎么动？" |

### 2.3 驱动（事后）—— 闭环循环

| # | 模型 | 关键问题 |
|---|---|---|
| 5 | 贝叶斯思维 | "结果对先验意味着什么？" |
| 10 | 复利 | "这判断是否让我在时间维度占便宜？" |
| T8 | 取舍 / 机会成本 | "我放弃了什么、得到了什么？" |
| T9 | 元认知 | "我的思考过程本身有 bug 吗？" |

## 3. 决策前 · 五镜复盘（5 分钟版 · 可直接用）

```markdown
## 决策：_______

### 🌳 木：基本事实（归根曰静）
- 这件事的本质是什么？
- 不可再分的事实有哪 3 个？
- **证伪** → 什么数据会推翻我？

### 🔥 火：连锁反应（为之于未有）
- 一阶：会发生什么？
- 二阶：然后呢？
- 三阶：谁会调整行为？
- **激励博弈** → 对方激励是什么？
- 不可逆后果有哪些？

### ⛰️ 土：系统视角（厚德载物）
- 这事在哪个大系统里？
- 有哪些反馈环？
- 杠杆点在哪？时间延迟多长？

### ⚔️ 金：致命排除（反者道之动）
- 什么会让这事彻底失败？
- 历史上类似的事怎么死的？
- **幸存者偏差** → 墓地里的失败者告诉什么？
- **安全边际** → 留多少余量？
- 我有没有避开这些死法？

### 🌊 水：证据更新（上善若水）
- 我现在有多大概率是对的？（先验）
- **复利** → 这判断是否让我在时间维度占便宜？
- 哪些新证据会让我改变？
- 我是不是只看了支持自己的？

### 最终
- 推荐方案：_______
- 信心：____% (贝叶斯后验)
- 必须监控的指标：_______
- 季度回顾时，回看哪 3 个指标？
```

## 4. 工具带（12 个 · 按需取用，不进日常）

| # | 模型 | 用途 | 阶段 |
|---|---|---|---|
| T1 | 奥卡姆剃刀 | 同等解释力下选最简单的 | 致 |
| T2 | 归纳 / 演绎 | 从具体到一般 / 从一般到具体 | 致 |
| T3 | 批判性思维 | 识别前提、识别谬误 | 致 |
| T4 | 地图 ≠ 实地 | 我的认知 ≠ 现实 | 致 |
| T5 | 圈定能力圈 | 这事在我的能力圈里吗？ | 致 |
| T6 | 约束 | 真问题诞生于真约束 | 行 |
| T7 | 共情 / 相对论 | 理解他人之前先理解他的位置 | 行 |
| T8 | 机会成本 / 取舍 | 选了 A 就丢了 B | 驱动 |
| T9 | 元认知 | 思考自己如何思考 | 驱动 |
| T10 | 抽样的回归 | 极端后必回归平庸 | 行 |
| T11 | 摩擦 / 黏度 | 任何动起来都有阻力 | 行 |
| T12 | 链上定理（反脆弱）| 反脆弱 / 杠铃策略 | 驱动 |

**哨兵（常驻监测，不挂在任何一格）**：
- 🎯 情绪 / 体感 — 数据之外的警报器
- 🧘 疲劳 / 状态 — 会污染所有模型

## 5. 实战话术（5 镜版）

| 场景 | 话术 |
|---|---|
| 想钻细节时 | 「先回到木」= 回到基本事实 |
| 想推演后果时 | 「上火看看」= 推演连锁反应 |
| 迷失在局部时 | 「站到土上」= 看整体 |
| 卡住找出口时 | 「上金刀」= 排除致命项 |
| 重复老路时 | 「水流一下」= 用新证据更新 |
| 完成决策时 | "这事走完五行了吗？" |
| 怀疑自己时 | "什么数据会推翻我？"= 证伪 |
| 找关键人时 | "他的激励是什么？" = 激励博弈 |

## 6. 季度回顾机制

> **每 90 天回头看一次**——避免加法陷阱

**复盘 3 个指标**：
1. 上季度决策中，**10 个核心模型**用过的有哪几个？
2. **跌过的跟头**在第几步？（致/行/驱动）
3. 模型**要添加还是降级**？（新增替换哪个？）

**纪律**：
- 核心层 10 个必须能脱口而出
- 工具带允许"忘了再查"
- 新增模型必须回答：替换哪个？补的是真盲区吗？
