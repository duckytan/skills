## 一、兵家「先知己后知彼」的元命题

### 1.1 核心命题

> **「昔之善战者，先为不可胜，以待敌之可胜」**  
> ——《孙子·军形篇》

| 张预注 | 含义 |
|---|---|
| 「**先为不可胜**」 | = 所谓"**知己**"者也 |
| 「**以待敌之可胜**」 | = 所谓"**知彼**"者也 |

### 1.2 「先胜」原则

> **「胜兵先胜而后求战，败兵先战而后求胜」**  
> ——《孙子·形篇》

- 先有胜利条件 → 再一战
- 先有胜利方案 → 再一战
- 先有胜利把握 → 再一战

**知彼诀含义**：先盘点内部能力（知己），再去调研外部方案（知彼）。

### 1.3 十三篇的「知己-知彼」分布（山鹿素行三段论）

```
始计 / 用间 —— 大纲（首尾呼应·三军所恃而动）
        ↓
  军形 / 兵势 / 虚实 —— 全在知己 ⭐
        ↓
  军争 / 九变 / 行军 —— 料敌知彼
        ↓
  地形 / 九地 / 火攻 —— 知天知地
```

**关键论断**：「**知己而后可军争**」—— 调研的工作流必须先内部盘点再外部调研。

## 二、阶段一·知己（内部盘点）

> **兵家定位**：调研的前置条件——不先知己就无法对标

### 2.1 系统 ❶·自我盘点·五事

**出处**：《孙子·始计篇》

> **「故经之以五事：一曰道，二曰天，三曰地，四曰将，五曰法」**

| 五事 | 兵家含义 | 知彼诀对应·自我盘点问题 |
|------|---------|------------------------|
| **道** | 令民与上同意，可与之死 | **团队/客户共识**：目标对齐？上下同欲？ |
| **天** | 阴阳、寒暑、时制 | **时机判断**：现在做合适吗？季节/窗口？ |
| **地** | 远近、险易、广狭、死生 | **资源盘点**：技术栈/人员/预算到位？ |
| **将** | 智、信、仁、勇、严 | **负责人能力**：leader 够强吗？缺什么素质？ |
| **法** | 曲制、官道、主用 | **流程制度**：文档/规范/流程完整吗？ |

### 2.2 系统 ❷·自我对标·七计（知己侧）

**出处**：《孙子·始计篇》

> **「主孰有道？将孰有能？天地孰得？法令孰行？兵众孰强？士卒孰练？赏罚孰明？」**

| 七计 | 兵家原义 | 知彼诀对应·自我对标问题 |
|------|---------|----------------------|
| **兵众孰强** | 哪方兵力强 | **我们的人手 vs 项目需要？** |
| **士卒孰练** | 哪方训练好 | **团队熟练度 vs 行业平均？** |
| **赏罚孰明** | 哪方赏罚分明 | **激励机制到位吗？** |
| **法孰行** | 哪方法令严明 | **流程/文档执行到位吗？** |

### 2.3 系统 ❸·自我判断·五事·胜算三要（知己侧）

**出处**：《孙子·地形篇》

> **「知吾卒之可以击，而不知敌之不可击，胜之半也」**

**知彼诀对应**：

| 胜算三要 | 含义 | 知己侧问题 |
|---------|------|-----------|
| **知吾卒之可以击** | 知我方能不能做 | **我们有能力做吗？** |
| **知地形之不可以战** | 知环境合适吗 | **环境/时机合适吗？** |
| **两者都知 = 胜算 1/2** | 单知己只能算一半 | **光知己不算完，还得继续知彼** |

### 2.4 系统 ❹·胜算判断·知胜五道（知己侧）

**出处**：《孙子·谋攻篇》

> **「故知胜有五：...上下同欲者胜；以虞待不虞者胜；将能而君不御者胜」**

| 知胜五道 | 知己侧问题 |
|---------|----------|
| **上下同欲者胜** | 团队共识到位吗？ |
| **以虞待不虞者胜** | 我们准备好 vs 没准备好？ |
| **将能而君不御者胜** | leader 够强 + 老板放手？ |

### 2.5 阶段一·核心原则

> **「不可胜在己，可胜在敌」** ——《孙子·军形篇》

| 不可胜（自己） | 可胜（敌人）|
|------------|-----------|
| 我能控制 | 我不能控制 |
| 必须做好 | 只能等待 |
| **知彼诀必须先做这一步** | **然后做下一步** |

### 2.6 阶段一·知彼诀输出

📜 **知己清单**（5 项必备）：

```
□ 团队/客户共识状态
□ 时机判断（现在做合不合适）
□ 资源盘点（人力/技术栈/预算）
□ 负责人能力评估
□ 流程/制度完备度
```

### 系统 ❻·虚实篇·侦察方法论（v4 新增·最重要）

> **《孙子·虚实篇》是孙武讲"知彼"最深的一篇**——v3 漏了最核心的。

| 原句 | 含义 | 知彼诀用法 |
|---|---|---|
| **「致人而不致于人」** | 掌握主动权，不被对方牵着走 | **调研要主动设议题，别被动看对方推送** |
| **「形人而我无形」** | 让对手暴露，自己隐藏 | **让对手信息充分暴露，自己的意图不外泄** |
| **「避实而击虚」** | 避开实的，打虚的 | **调研找对方薄弱点，不硬碰强项** |
| **「我专而敌分」** | 我集中，敌分散 | **调研聚焦关键问题，不被海量信息带偏** |
| **「冲其虚也」** | 攻其空虚处 | **调研直击对方没做好的地方** |

> **虚实篇 = 孙武的"侦察/情报"专篇**——知彼诀最该学的核心。

### 系统 ❼·军形篇·度量数称胜·量化评估链条（v4 新增）

> **《孙子·军形篇》给了一个完整的量化评估公式**——非常适合调研的定量分析。

> **「一曰度，二曰量，三曰数，四曰称，五曰胜。地生度，度生量，量生数，数生称，称生胜」**

| 步骤 | 含义 | 知彼诀用法 |
|---|---|---|
| **度** | 丈量（地形广狭）| 界定调研范围 |
| **量** | 计量（资源多少）| 量化对方资源 |
| **数** | 计数（兵力多寡）| 统计对方数据 |
| **称** | 权衡（轻重对比）| 我方 vs 对方对比 |
| **胜** | 判胜（胜负判断）| 得出调研结论 |

> **五步链条 = 调研的完整定量流程**——从"界定范围"到"得出结论"，每一步都有明确的量化动作。

## 九、知彼诀的"兵家背书"一句话总结（v4 更新）

> **调研 = 兵家「先知己后知彼」的三阶段体系**

>
> **核心命题**：「不可胜在己，可胜在敌」—— 先做好自己能做的，再去看对方。
>
> **核心代表人物**：孙武（兵圣）——「知彼知己」这句话的主人，五事七计/五间/料敌/虚实/度量数称胜全部出自《孙子兵法》。
