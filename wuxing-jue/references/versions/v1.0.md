## 0. 核心框架

```
        ┌──── 木 · 第一性原理 ────┐
        │  拆到基本事实 (根)        │
        ▼                          ▲
   水 · 贝叶斯思维                火 · 二阶思维
   持续更新 (流)                  推演连锁 (蔓)
        ▲                          │
        │                          ▼
        └──── 金 · 逆向思维 ────┘
           排除致命 (断)
                    ▲
                    │
              土 · 系统思维
              看清整体 (容)
```

> 五镜 = 5 个思维 | 五行 = 5 个属性 | 闭环 = 决策完整链路

## 1. 五镜 · 五行速查表

| 五行 | 五镜 | 核心字 | 老子原话 | 一句话用法 |
|---|---|---|---|---|
| **木** 🌱 | 第一性原理 | **根** | 「归根曰静」| 拆到不能再拆的基本事实 |

## 2. 相生闭环（决策完整链路）

```
木 → 火 → 土 → 金 → 水 → 木
↑                              ↓
└────────── 回到拆解 ←──────────┘
```

| 步 | 五行 | 动作 | 关键问题 | 老子 |
|---|---|---|---|---|
| 1 | 木 | **拆** | "这是什么？基本事实是什么？" | 归根曰静 |
| 2 | 火 | **烧** | "然后呢？接下来会发生什么？" | 为之于未有 |
| 3 | 土 | **容** | "整体什么样？哪些反馈环？" | 厚德载物 |
| 4 | 金 | **断** | "什么会毁掉它？砍掉致命的" | 反者道之动 |
| 5 | 水 | **流** | "新证据是什么？我该更新什么？" | 上善若水 |

**每步完成后问一句**：能不能进到下一步？如果不能，回到木重新拆。

---

## 3. 相克纠偏（避坑清单）

| 五行 | 过度使用的征兆 | 怎么纠偏 |
|---|---|---|
| **木克土** | 拆得太细，看不到整体 | 提醒自己"回到全局" |
| **土克水** | 框架太死，拒绝更新 | 主动找反例 |
| **水克火** | 太理性，不敢推演 | 允许自己"先想大胆的" |
| **火克金** | 想太多，做不了减法 | 强制砍掉 80% 选项 |
| **金克木** | 只挑刺，不建设 | 至少给一个正向方案 |

## 4. 决策前 · 五镜复盘（5 分钟版）

```markdown
## 决策：_______

### 🌳 木：基本事实
- 这件事的本质是什么？
- 不可再分的事实有哪 3 个？

### 🔥 火：连锁反应（为之于未有）
- 一阶：会发生什么？
- 二阶：然后呢？
- 三阶：谁会调整行为？
- 不可逆后果有哪些？

### ⛰️ 土：系统视角
- 这事在哪个大系统里？
- 有哪些反馈环？
- 杠杆点在哪？
- 时间延迟多长？

### ⚔️ 金：致命排除
- 什么会让这事彻底失败？
- 历史上类似的事怎么死的？
- 我有没有避开这些死法？

### 🌊 水：证据更新
- 我现在有多大概率是对的？
- 哪些新证据会让我改变？
- 我是不是只看了支持自己的？

### 最终
- 推荐方案：_______
- 信心：____% (贝叶斯后验)
- 必须监控的指标：_______
```

## 5. 实战话术（直接可用）

| 场景 | 话术 |
|---|---|
| 想钻细节时 | 「先回到木」= 回到基本事实 |
| 想推演后果时 | 「上火看看」= 推演连锁反应 |
| 迷失在局部时 | 「站到土上」= 看整体 |
| 卡住找出口时 | 「上金刀」= 排除致命项 |
| 重复老路时 | 「水流一下」= 用新证据更新 |
| 完成决策时 | "这事走完五行了吗？" |
