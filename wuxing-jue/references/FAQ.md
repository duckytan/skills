## ❓ Q1：五行诀 = 中医五行吗？

**简短回答**：**不是**。本 skill 的"五行"指**道家内炼五行**（性/情/精/气/神），不是中医的脏腑五行。

**详细对比**：

| 维度 | 中医五行 | 五行诀的五行 |
|---|---|---|
| **本质** | 5 种**物质/器官** | 5 种**内炼维度** |
| **"行"是** | 名词（Five Elements 误译）| 动词（Five Movements·运动）|
| **5 行指** | 金/木/水/火/土 = 物理 | 性/情/精/气/神 = 认知功能 |
| **起源** | 《尚书·洪范》→ 黄帝内经 | 《云笈七签》→ 悟真篇 |
| **核心问题** | "这病怎么治"？| "这决策怎么想"？|

> **中医五行 = 物理学的"5 种基本粒子"**（描述物质结构）  
> **五行诀五行 = 算法学的"5 种基础算法"**（描述思维方法）

**出处依据**：
- 「诀」= **内炼心法**（《云笈七签》"诀者，修炼之枢机也"）
- 5 维修仙术语（太初/观复/洞观/颠倒/知几）= **100% 道家/易经原文**（由般若 AI 公司右脑·般若虾审阅）

## ❓ Q2：五行诀 = 算命/风水吗？

**简短回答**：**不是**。本 skill 是**认知方法**（决策/复盘/审方案），不是预测术。

**详细说明**：

- 算命/风水 = 预测未来 · 基于"天机/命理"
- 五行诀 = 思维方法 · 基于"5 维 + 8 关系"
- 算命用五行 = 占卜工具
- 五行诀用五行 = **认知隐喻**（借名不借术）

**判别方法**：问自己——
- 这是在预测"会发生什么"吗？ → **不是**五行诀
- 这是在思考"该怎么想/做"吗？ → **是**五行诀

## ❓ Q4：五行诀 = 西方 5 思维模型的"换皮"吗？

**简短回答**：**不是简单换皮**——是**东方哲学的独立框架**，但**核心结构与西方 5 步共识**。

**5 步跨文化对比**：

| 系统 | 5 步 | 起源 |
|---|---|---|
| 五行诀 | 太初/观复/洞观/颠倒/知几 | 2026 道家内炼 + 西方 5 思维 |
| Dewey 反思性思维 | 暗示/问题/假设/推理/验证 | 美国·杜威 1933 |
| 唯识五重 | 遣虚存实/舍滥留纯/摄末归本/隐劣显胜/遣相证性 | 唐代·法相宗 632-682 |
| Cynefin 5 域 | 清晰/繁杂/复杂/混沌/无序 | 1999·Dave Snowden |
| 道家内炼五行 | 性/情/精/气/神 | 北宋《云笈七签》|

> **5 步在跨文化认知工作流中反复出现——不是巧合。**

**五行诀的独特价值**：
- 5 维 + 8 关系动态平衡 = 西方 5 步 + 中医/道家关系论
- 不是照搬任何一传统 = **融合创新**

## ❓ Q5：五行诀 = 玄学吗？

**简短回答**：**不全是**——核心是**认知方法**（实用），修仙术语只是**命名灵感**（美学）。

**两层结构**：

| 层 | 内容 | 性质 |
|---|---|---|
| **功能层** | 5 维内炼心法（太初/观复/...）+ 8 关系动态平衡 | 实用·可证伪·决策方法 |
| **命名层** | 修仙术语（道家/易经/云笈七签）| 美学·东方气质·传播性 |

> **「诀」= 内炼心法，不是咒语，不是外用符箓——是思维修炼的内炼口诀**  
> 出处：《云笈七签》卷四十六「诀者，修炼之枢机也」

## ❓ Q9：五行诀能审五行诀自己吗？（**自审边界**）

**简短回答**：**部分能·部分不能**。**单维自检 OK·5 维全跑 = 红线**。

### ✅ 能用（3 场景）

| 场景 | 怎么做 | 风险 |
|---|---|---|
| **单维自检** | 颠倒诀自检 / 知几诀自检 / 太初诀自检（**只跑 1 维**）| 🟢 绿 |
| **5 维各 1 问** | 太初 1 + 颠倒 1 + 知几 1（**不全跑 5 维**）| 🟡 黄 |
| **元评估**（"5 维框架靠不靠谱"）| **必须 /scrutiny 或般若虾外部审** | 🟡 黄 |

### ❌ 不能用（3 红线）

| 红线 | 为什么错 |
|---|---|
| **5 维全跑审 5 维** | **同义反复** = 维度折叠 = 零信息 |
| **自评"8 关系判定"自洽** | **裁判兼运动员** = 失去外部性 |
| **自评"5 维哲学纵轴"** | **元问题** = 不是五行诀的工作 = /scrutiny 职责 |

### 3 个不能用案例

#### ❌ 案例 1：5 维全跑审 5 维

```
❌ "五行诀审五行诀：跑全 5 维 + 8 关系核验"
```

**为什么错**：5 维审 5 维 = **用工具审工具** = 同义反复。颠倒诀被调用 5 次（Pre-Mortem / 否定 / 反方 / 实态核验 / 自审）= **已经不是 5 维，是 1 维（颠倒）**。

#### ❌ 案例 2：自评 8 关系判定

```
❌ "五行诀自评：生克乘侮化害胜复 8 个够不够？"
```

**为什么错**：**裁判兼运动员** = 失去外部性。8 关系判定必须 /scrutiny 风险等级或般若虾外部审。

#### ❌ 案例 3：自评 5 维哲学纵轴

```
❌ "五行诀自评：5 维是不是真的 5 维？"
```

**为什么错**：**元问题** = 不是五行诀的工作。元评估必须 /scrutiny 第 6 步实态核验或般若虾联网核验。

### 3 个能用案例

#### ✅ 案例 1：单维自检

```
✅ "颠倒诀：检查 [v4.0.5 skill] 哪里会失败"
✅ "知几诀：我对 [v4.0.5 拍板] 现在把握多少"
✅ "太初诀：[五行诀方法] 的 3 个基本事实"
```

**为什么 OK**：单维 ≠ 5 维全跑 = 不折叠。

#### ✅ 案例 2：5 维各 1 问

```
✅ "五行诀审 [方案]：
   - 太初：3 个基本事实
   - 颠倒：1 个最大风险
   - 知几：1 个置信度
   - 观复 + 洞观：跳过"
```

**为什么 OK**：不全跑 5 维 = 不折叠。

#### ✅ 案例 3：元问题外部验证

```
✅ "五行诀自评 5 维框架靠不靠谱？
   → 走 /scrutiny 第 6 步实态核验
   → 走般若虾外部审"
```

**为什么 OK**：元问题 = 框架问题 = **必须外部验证**。

### 关键洞察

> **5 维是种类序**（5 种工具）**不是主框架**。**5 维全跑审 5 维 = 把工具当主框架** = 7-6 v3.0 错误。**五行诀的边界 = 单维自检 OK + 5 维全跑 = 红线**。

### /scrutiny v3.0 自审验证（2026-07-07 11:00）

- **质量评分**：20/20
- **风险等级**：🟡 黄（5 维全跑 🔴 / 单维自检 🟢 / 元评估 🔴）
- **根因**：5 维 = 种类序·不是主框架
- **对外宣传价值**：「五行诀的边界 = 单维自检可以，5 维全跑不可以」
