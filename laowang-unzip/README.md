# 老王解压 · laowang-unzip

百度网盘 / 阿里云盘下载回来一堆「伪装成 mp4 / png / txt」的压缩包？这条流水线帮你**安全、幂等、可审计**地一键清干净。

> 目标不是「解压」，是「安全清理」。判据全部来自 46GB / 200+ 真实批次的踩坑，不靠拍脑袋。

---

## 为什么写它（真正的意义）

- 下载目录里大半是伪装压缩包，手动解压 + 删除极易**误删、极易占满盘、极易删了源包又解不开**。
- 哪些该删、哪些要先问、哪些绝不碰 —— 每一条都来自真实批次踩坑，沉淀成可复用的判据。
- 删之前先做 12 道检查，全过才删；删完默认进 Windows 回收站，**一键可找回**。

## 亮点

- **崩溃安全**：单线程 + SQLite 状态机，`kill -9` 重启接着跑，不重复解压、不丢进度。
- **伪装包全谱修复**：前导垃圾截掉取真包 / 魔数被改（`UA`→`PK`）自动补 / 分卷自动拼接 / 首卷改名识别。
- **12 道删除检查**：全过才删，且默认走回收站，删错能找回。
- **空间感知**：解压前先清回收站、按「体积 ×1.5 + 6GiB」闸门、三路空闲交叉校验，杜绝解一半盘满。

## 特色

- **密码试解**：文件名 / 父目录名末尾配对括号（5 种 `（）()【】[]{}`）+ 提示词同义词（解压码 / 提取码 / 口令…）自动抠取；
  标准来源全失败后，还会去**已解压出来的 `.txt` 文档**里挖密码做最后兜底（`密码.txt` 首行、`解压密码：xxx` 等）。
- **随手加密码**：`pipeline.py add-password "<密码>" [--test]` 一条命令入库并立即重试密码失败的包。
- **自进化**：真实批次踩坑写入 `lessons.md`，复现 ≥2 次或 P0 才升为正式判据，越用越准。
  已**机械化**并有闸口：`pipeline.py evolve` 做健康度自检（欠账在 `doctor` 第 7 项**只提示、不影响开工**，
  另见批次报告第十一节）+ 候选挖掘（只读 events/files）+ 补齐「复现」次数与归档（写前必备份）；
  **收尾闸口** `evolve --check` 不通过则本批不得收尾。
- **安全分级**：自动 / 先问 / 绝不自动，三类行为分明，不替你做危险决定。

## 快速开始

1. 把待处理文件丢进 `【new】` 目录
2. 跑流水线 `pipeline/`
3. 看报告，确认无误后产物进 `【done】`

## 安全分级

| 等级 | 行为 |
|------|------|
| 自动 | 判据充分、零风险，直接处理 |
| 先问 | 有歧义或不可逆，先确认再动 |
| 绝不自动 | 高风险，只报告不操作 |

## 已知限制

- Windows 专用（依赖回收站 / 回收站 API）。
- 分卷需首卷完整才能拼；魔数严重损坏的包需人工补。
- 个人密码库（`password.txt` 等）**不会**被上传或外泄。
