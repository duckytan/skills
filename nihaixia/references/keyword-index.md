3. 拿到 5 字段体质判定 + 十问症状 → 进 SKILL.md 主体六经辨证流程
4. **用户说「倪海厦 skill 更新」/「海厦更新」** → AI 应先跑 `python3 scripts/update_check.py` 检测 GitHub 新版本（<7天跳过，否则联网比对·有新版提示用户去源头仓库）
